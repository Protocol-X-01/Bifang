# Brand pack — project handoff checklist

Protocol-X requested a reusable logo and promotional pack for every project. Include this checklist in future project handoffs and adapt it to the project's existing identity.

## Identity

- [ ] Identify the approved mark, wordmark, colours and project line.
- [ ] Keep editable vector masters and the source used to create them.
- [ ] Export symbol, horizontal and stacked arrangements.
- [ ] Supply light-surface, dark-surface, white and black versions.
- [ ] Check the mark on both light and dark backgrounds.
- [ ] Test legibility at small sizes and create a simplified favicon where needed.
- [ ] Convert final logo lettering to outlines; include editable type sources and font licences.
- [ ] Provide transparent PNGs at practical sizes plus avatar tiles and favicon formats.

## Promotion

- [ ] Create at least three distinct thumbnail directions using the project's own style.
- [ ] Include a social preview, square post, vertical cover and profile/channel banner.
- [ ] Keep the focal content inside the platform's crop-safe area.
- [ ] Include clean backgrounds and editable layouts for future announcements.
- [ ] Use real product captures; tie visible claims to the exact demonstrated result.
- [ ] Record generated-image prompts, mode and original inputs when used.

## Handoff

- [ ] Include an offline visual catalogue, palette, usage guide and asset index.
- [ ] Inspect complete compositions and small-size exports visually.
- [ ] Check dimensions, transparency, margins, portable image references and missing assets.
- [ ] Keep source/font credits and the relevant licences in the pack.
- [ ] Generate a checksum manifest and one downloadable archive.
- [ ] Save the pack alongside the project and record its location in project continuity.
- [ ] Treat publishing, account branding changes and app-icon replacement as separate actions.
